## Детали

- [ ] Интеграция VK Video Live: ingress (чаты/события), авторизация канала, статусы стрима — по образцу twitch-платформы
- [ ] Интеграция YouTube: ingress (чаты/события), авторизация канала, статусы стрима — по образцу twitch-платформы
- [ ] Чат на сайте: пользователь входит через Twitch (flow уже есть). Отдельно — чат на странице стрима вместо встроенного чата Twitch. Наш чат должен попадать в общий поток событий платформ
- [ ] Виджет-агрегатор чатов: собирает чаты со всех платформ (VK, YouTube, Twitch и наш сайтский чат) и показывает их в виде горизонтальной полосы на HTML-странице (тему для оформления найду)
- [ ] Подключение ODA — донатная платформа; документацию найду
- [ ] редактирование действий и правил надо переделать, сделать по аналогии со streamerbot (понадобится создать какую-то очередь супер-действий)
- [ ] Нормальная админка для управления наградами: видеть, создавать и редактировать награды за баллы канала прямо из панели, не заходя в Creator Dashboard (Twitch API: `POST /helix/channel_points/custom_rewards`, scope `channel:manage:redemptions`). Бонус: у наград, созданных приложением, появляется полное управление
- [ ] Автофулфилл редемпшенов как экшен движка правил. Ограничение Twitch: приложение может фулфиллить только те награды, которые само и создало (см. пункт про админку наград); к ручным наградам стримера доступа нет
- [ ] Правила/движок: Событийный поток наружу (WS/оверлей) — спроектировать отдельно от шины B, когда понадобится (напр., как новые экшены с собственной шиной; сейчас виджет уже читает очередь через `/wapi/queue`)
- [ ] Правила/движок: Новые матчеры и условия правил (кроме `MessageContains`/`RewardId`), кулдауны и лимиты на юзера, порог стоимости награды
- [ ] Правила/движок: Плагины экшенов без кода (скрипты/UI-редактор)
