# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

SvelteKit 3 (Svelte 5 runes), Vite, prerendered static build (`adapter-static`), plain CSS with custom-property tokens. No UI framework.

## Users

- Зрители канала Sapa TV: заходят посмотреть/найти трансляцию, открыть ссылки на Twitch, VK Video и YouTube, попасть на страницу прямой трансляции с плеером и чатом.
- Стример (админ): использует док-панель и OBS-виджет «Рулетка» для управления очередью раздачи и её отображения в эфире. Эти две поверхности доступны только по ключу `?pak=` и не предназначены зрителям.

## Product Purpose

sapa-tv.ru — небольшой персональный хаб канала «Sapa TV». Даёт зрителям лаконичные точки входа на трансляции вне площадок, собственную страницу прямого эфира с плеером и чатом, а админу — инструменты раздачи (очередь, управление спином, OBS-виджет). Сейчас сайт открывается как «Скоро открытие».

## Positioning

Не вторая площадка, а собственная «витрина» стримера: домен ведёт на живые каналы, и на самой витрине можно смотреть эфир и участвовать в раздаче. Отличие от простой ссылки-био — поддержка собственной трансляции и раздаточных механик.

## Operating Context

- Зрители приходят с Twitch/VK/YouTube или по прямой ссылке; главная сейчас — лаунчер «скоро открытие» с кнопками на каналы.
- Прямой эфир открывается на `/stream`: FLV-поток через mpegts.js + чат Twitch iframe, кнопки донатов.
- Раздача: очередь `/api/queue` (REST) + события через WebSocket `/ws` (`spin_started`, `spin_completed`, `spin_error`). Слоты имеют редкость (common / uncommon / rare / mythical / legendary / track-ы).
- Док-панель `/dock`: управление очередью (dequeue, complete, cancel, добавить, лог). Виджет `/roulette`: отображение спина в OBS. Обе только с `?pak=КЛЮЧ`.
- API на `localhost:3000` (в dev); планируются и другие страницы канала.

## Capabilities and Constraints

- Светлая и тёмная тема (переключатель + `prefers-color-scheme`, тема сохраняется в localStorage).
- Требование владельца: дизайн-токены светлой и тёмной темы должны **вычисляться из базовой(ых) цветов(!) через OKLCH**, а не задаваться каждому — не каждый токен вручную в hex.
- Токенов уже выдержаны Material-имена (`--primary`, `--surface-container-*`, `--on-*`, `--outline-*` и т.п.); семантические роли менять не требуется, важна их производная структура.
- Русскоязычный интерфейс (кроме англ. полей API: статусы очереди `Pending|Spinning|Completed|Cancelled|Error`).
- Имиджи аватара персонажа `static/avatar.png`; изображения редкости слотов в `html/static/roulette/`.
- Статический prerender: все внешние данные приходят клиентом по fetch/WS.

## Brand Commitments

- Имя и домен: «Sapa TV», sapa-tv.ru.
- Каналы-площадки с фиксированными фирменными цветами, сохраняемыми в фирменных местах (не перекрашивать): Twitch #9146FF / #7727E8, VK Video #0077FF / #0065DD, YouTube #FF0000 / #CC0000.
- Кросс-канальная кнопка доната: sapushka.oda.digital, «💰 На поддержку сервера» и «🍖 Торну на еду».
- Ник-стримера: «Сапушка» (sapushka_). Персонажная иконка на главной — «Персонаж Sapa TV» (avatar.png).

## Evidence on Hand

- Существующий код-инвентори: `src/styles/theme.css` — полные токены light/dark, `src/styles/site.css`, страницы `/`, `/stream`, `/links`, `/dock`, `/roulette`, `html/` — старая статическая версия.
- Демо-контент для редизайна нужен; референсы собираются из существующих страниц.
- Нет официальной палитры-вербалки, нет фирменного шрифта.

## Product Principles

1. Одним взглядом: зритель в первые секунды понимает, что это канал Sapa TV, что открывается и куда нажать.
2. Каналы на первом плане: действия «Смотреть» ведут на площадки и эфир, без барьеров.
3. Единая система цветов из базовых OKLCH-семян: темы — производные одной палитры, а не разрозненные hex.
4. Стримерские поверхности (док, виджет) — операционные: знание надзорных нарядов, состояние видно мгновенно.
5. Лёгкая расширяемость: токены и сери вдоль, чтобы новые страницы присоединялись без интеграции палитры.

## Accessibility & Inclusion

- Поддержка тёмной темы (ночное просмотр) и переключателя.
- Контраст текста на фоне обеих тем; у брендовых кнопок Twitch/YouTube/VK — производительный контраст поверх чужого цвета.
- Рус после деф рус; доступные fallback-шрифты.
